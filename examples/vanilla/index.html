Kuber Player

Vanilla JavaScript & custom HTML5 tag integration showcase.

Method 1: Programmatic Constructor

Method 2: W3C Custom HTML Tag

JavaScript SDK setup

Import the bundle and instantiate `KuberPlayer` inside a selector:

import { KuberPlayer } from './kuber-player.esm.js';

const player = new KuberPlayer({
  container: '#kuber-js-player',
  src: 'http://localhost:8080/api/v1/video/123/playlist',
  poster: 'http://localhost:8080/api/v1/video/123/thumbnail',
  spriteVtt: 'http://localhost:8080/api/v1/video/123/sprite',
  autoplay: false,
  muted: false
});

Web Component setup

Simply register the element file and place the custom tag directly in your static HTML code:

<!-- Import script once -->
<script src="kuber-player.umd.js"></script>

<!-- Declare tag anywhere -->
<kuber-player 
  src="/api/v1/video/123/playlist"
  poster="/api/v1/video/123/thumbnail"
  sprite-vtt="/api/v1/video/123/sprite">
</kuber-player>
